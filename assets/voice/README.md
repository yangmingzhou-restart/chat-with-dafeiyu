# 默认参考音

- 文件：jm-tech.wav（24000Hz、单声道、10.72275秒）。
- 逐字转写：jm-tech.txt，克隆时与该音频配对。
- 来源：本项目维护者原先选定的“即梦·技术说明”参考片段，经允许公开用于工程运行和复现；不是聊天录音。
- 默认同一音频同时用于prompt和reference，5步、CFG2.0、seed0；不从其他片段随机选人。

校验值在docs/reference-voice.json。要替换音色，优先使用网页导入自己的单声道干净人声并填写准确转写，不要只覆盖文件却保留旧校验值。

声音资源与软件代码的许可范围见根目录THIRD_PARTY_NOTICES.md。
