# 普通Wi-Fi与热点怎么选

**作者选择手机热点，是因为校园网通常需要网页登录、设备绑定或802.1X认证，ESP32接入不方便。并不是ESP32只能连手机热点。**

## 有普通Wi-Fi时，直接连接即可

- ESP32使用该路由器的**2.4GHz、WPA2-Personal/AES**网络。本版不实现校园网页认证、WPA2-Enterprise或WPA3-only。
- 电脑连接同一路由器。电脑可以走2.4GHz、5GHz或网线，关键是电脑与ESP32处于可互通局域网；不是要求电脑也必须用2.4GHz。
- 在`首次配置.cmd`中填写自己的Wi-Fi名称和密码，并按FLASHING.md重新编译固件，确保电脑配置和固件一致。
- 如果是访客网络、AP/客户端隔离网络，即使显示相同SSID也可能无法互通。使用普通内网或关闭对应隔离功能后再试。

## 没有方便的普通Wi-Fi时，用热点

手机开启2.4GHz/WPA2热点，让电脑与ESP32加入。DeepSeek走互联网，所以手机需提供可用上网连接。首次下载模型有数GB，建议在方便下载的网络提前完成。

Release预编译固件只写入公开演示配置：SSID=`DAFE_DEMO`，密码=`dafe-demo-1234`。这是演示值，不是作者的网络凭据。为快速试用，可把热点设置成这两个值；正式使用或连接自己的路由器，建议按教程重新编译，填自己的值。

## 后台连接机制

ESP32是Wi-Fi STA和WebSocket客户端；电脑运行服务。ESP32通过UDP18767接收电脑的子网定向广播，再连接电脑TCP18765的`/audio`。不需手填不断变化的电脑IP。

启动器会等待配置的SSID可见后才让电脑连接；配置的SSID也可以是普通路由器，并非只识别热点。未发现前不主动断开当前Wi-Fi。该助手仅适用于Windows无线网卡；电脑已经通过网线接入同一局域网时，设备发现服务仍可经网线正常工作，不要求额外启动移动热点。

Windows防火墙需允许项目Python在所用网络配置下接收TCP18765和UDP18767。先允许此Python程序，不必关闭整个防火墙。管理网页只在`127.0.0.1:18766`开放，手机不能使用这个地址访问电脑页面。

当LLM也切到本地且权重已下载后，运行本身不要求互联网；使用云端LLM/ASR/TTS时，则电脑必须能访问对应API。
