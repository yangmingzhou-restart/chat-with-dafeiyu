# 网页使用

环境和固件首次配置完以后，日常只需要：让电脑和ESP32接入可互通的普通Wi-Fi/热点，给ESP32供电，双击`启动大肥鱼.cmd`，等待模型就绪。网页地址为 **http://127.0.0.1:18766/**。

重复启动会复用原服务，不重复加载模型。浏览器没自动打开就手动输入地址。关闭网页不会退出后台，退出请双击`关闭大肥鱼.cmd`。

## 切换对话

左侧“最近”或“项目”中点击对话只浏览；新建也不会自动抢占设备。点击右上角**确定启用**，才切换ESP32上下文。顶部始终显示设备当前启用的对话。

确认后旧回答会停止，旧任务清理，目标模型准备好后提交切换。失败保留原对话并尝试恢复原模型。音频连接会短暂断开重连，目的是丢弃旧录音包，不是需要重新刷固件。

不同对话有各自的消息、配置和摘要，项目只分组、不共享记忆。可以把同一件事告诉A，再启用B询问，B不应知道；切回A应仍记得。重启后聊天记录和启用对话会恢复。

## 打字、讲话和停止

网页打字默认只显示回答；勾选“本次朗读”后才用ESP32播放这一轮，因此要先启用当前对话且设备在线。麦克风对话则正常朗读。喇叭回答结束后再讲话，当前没有插话/AEC。

方形按钮停止当前回答。系统不会在开机或待机播放提示音。识别文字和回答会进入聊天区，状态栏显示监听、识别、摘要、思考、合成和播放状态。

顶部可切换LLM模型；选择另一个连接后可进入设置完善该模型。回答期间先停止再保存配置，避免改动正在执行的一轮。

## 长对话和隐私

完整聊天保存在本机`.private/studio.sqlite3`。默认超过20轮或接近上下文预算时，为旧消息生成本对话摘要，保留最近8轮；摘要不删除原文，不共享给其他对话。摘要失败可在消息下重试文字回答，不偷偷超预算发送。

外部模型会收到对应的音频/文字输入；完全本地的三段模型配置则不需要把内容发给云端。原始录音和回答WAV保存在runtime，不上传到GitHub。备份时停止工作台后备份.private和需要保留的runtime，数据库中的DPAPI密钥不能直接跨Windows账户解密。

页面能打开不等于ESP32已经连接；以设备卡和状态为准。管理网页仅供本机使用，不作为开放到公网的多人服务。
