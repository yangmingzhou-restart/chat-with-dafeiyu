# 常见问题

| 现象 | 处理 |
|---|---|
| 网页打不开 | 先双击启动大肥鱼.cmd，再打开http://127.0.0.1:18766/；确认不是直接在ZIP里运行 |
| 提示端口被占用 | 关闭另一份本项目或旧server.main，不杀不认识的Python服务 |
| 启动模型失败 | 页面仍可打开；进入设置检查模型目录、权重、API Key和参考音，修正后重试 |
| 提示缺少py或Python | 安装Python3.12及py启动器；或配置DAFE_PYTHON使用自己的可用解释器 |
| CUDA不可用/OOM | 检查NVIDIA驱动和CUDA版torch；关闭不需要的GPU任务，合计本地LLM与TTS显存。不要只看权重文件大小 |
| 模型下载失败 | 使用MODELS.md的ModelScope路径或手动下载完整目录，不让启动过程反复隐式下载 |
| ESP32未连接 | 确认供电、2.4GHz/WPA2、SSID和固件一致、局域网互通、防火墙允许；普通Wi-Fi也可用 |
| 能连网但发现不了电脑 | 检查UDP18767、TCP18765及AP隔离。电脑与ESP32需可互通，不是仅同SSID |
| COM口不出现 | 检查数据线、USB口和CP210x/对应芯片驱动，插拔确认端口 |
| 烧录Connecting失败 | 关闭监视器，必要时按BOOT配合EN；先备份，不盲目擦Flash |
| 待机没有声音 | 正常；固件默认关闭播放TX，只在回答时开启 |
| 只有起始噪声 | 先检查电脑保存的下行WAV是否清晰，再核对引脚、字节数/时钟、功放使能与供电，不凭DMA完成断定喇叭正常 |
| 音色像换人 | 必须有唯一参考音+正确转写，检查设置与参考缓存；不能退回无参考合成 |
| 低步数噪声大 | 1/2/3步实测不合格，恢复5步再试 |
| 喇叭音质差 | 对比同一文件在电脑和喇叭的效果；小喇叭、供电、接点、I²S和合成质量都可能影响，不直接归咎采样率 |
| 切换后短暂断连 | 正常设计，用新连接隔离旧录音包；失败应保持原对话，检查错误提示 |
| 摘要失败 | 保留原始历史，在失败消息下重试；不要手动把另一个对话摘要复制进来 |
| 新电脑解不开数据库密钥 | DPAPI绑定Windows用户；新机器重新填自己的Key，不共享原作者数据库 |

原型排查过的真实缺陷包括：Windows相对sleep积累使20ms包发送变慢；100Hz RTOS把5ms等待取整为0导致空转；热点全局广播不可达，改为按网卡掩码定向广播；无参考合成造成音色漂移。已在当前实现中处理。

最初“只有起始噪声”的唯一根因没有隔离：断电核对接点和诊断固件更新后恢复，不能把某一项改动写成唯一原因。当前固件保留引脚PCNT计数诊断；它只能反映ESP32管脚反馈，不能代替功放端仪表测量。
