# v0.1.0 发布检查

- 公开整理后的 Python 源码：32 项 unittest 通过。
- 前端：TypeScript 检查和 Vite 生产构建通过，已包含预构建文件。
- 公开固件：ESP-IDF 5.3.4 编译通过，应用大小 855200 字节；只包含演示网络 `DAFE_DEMO`，不是作者的真实 Wi-Fi。
- 依赖：现有 Python 3.12 环境导入检查通过，requirements 的 pip dry-run 解析通过；没有在全新电脑上完整安装验证。
- 模型：作者现有 Paraformer / VoxCPM2 权重文件记录了 SHA256。权重不打入软件包，按模型文档单独下载。
- 界面图使用人工编写的演示对话，不是作者聊天数据库。
- 原型硬件已通过真实麦克风、喇叭、多轮对话，以及 A 记住信息、B 不知道、回到 A 仍记住的验收。公开固件重新编译后没有重新烧入作者设备，因此不声称这个演示 SSID 的固件已经再次完成硬件验收。
- 参考音和转写经作者明确同意公开；不包含聊天录音、API 密钥、真实 Wi-Fi、数据库或原设备完整 Flash 备份。

性能数字、其他厂商接口的实测范围及显存限制见 [性能说明](PERFORMANCE.md)。联网方式见 [网络说明](NETWORK.md)：校园网认证不方便才使用热点；普通 2.4GHz Wi-Fi 可直接连接。
